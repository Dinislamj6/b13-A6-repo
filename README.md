📍 Project Name : DiGiTools PlatForm 

📝Description : 
DigiTools is a modern and responsive web application built with React that allows users to explore and purchase various digital tools and services. The platform provides a clean and interactive UI where users can view products, check features, and add items to their cart seamlessly.

It includes dynamic product rendering, cart management functionality, and real-time user feedback using toast notifications. The application is designed following a component-based architecture with a focus on performance, usability, and responsive design across all devices.



⚙️Technologies Used:

⚛️ React.js
🎨Tailwind CSS
🌼DaisyUI
🌍 Netlify (Deployment)
🧑‍💻 Git & GitHub
🎯JavaScript (ES6+)
🔔React Toastify
♦️JSON (for product data)

✨ Features
🛒 1. Cart Management System
*Add products to cart
*Remove individual products
*View total selected items in navbar
*"Proceed to Checkout" clears all cart items

🔄 2. Product & Cart Toggle System
*Toggle between Products and Cart section
*Default view shows all products
*Empty cart message when no items added

🔔 3. Real-time Notifications
*Toast messages for:
*Add to cart
*Remove product
*Checkout action
